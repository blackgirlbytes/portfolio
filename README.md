# Rizel Scarlett — Developer Relations Portfolio

A single-page portfolio built for hiring managers and recruiters: skill sets, featured work,
writing, talks, open source, podcasts, streams, and community — all one click from the sticky nav.

## Stack

- Next.js (App Router) + React 19
- Tailwind CSS v4
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy

Push to GitHub and import the repo on Vercel (or any Next.js host). No environment variables needed.
